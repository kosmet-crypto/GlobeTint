# GlobeTint

Мапа посећених земаља и трошкови путовања, као Android апликација (APK).

## Статус

Фаза нацрта. `design/mockup.html` приказује главне екране (отвара се у прегледачу),
а `design/screens/` садржи снимке тих екрана.

Подаци о границама: Natural Earth преко `world-atlas`. При цртању се Косово спаја са Србијом,
Северни Кипар са Кипром и Сомалиленд са Сомалијом.
